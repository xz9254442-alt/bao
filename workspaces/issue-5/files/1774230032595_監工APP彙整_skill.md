# 監工APP 彙整技能

## 任務概述

將三個檔案彙整為一份完整的「監工APP」格式 Excel 報表，核心工作是：
1. 以 **ExportDispatch CSV**（監工APP系統匯出）為主體資料
2. 用 **活頁簿2.xlsx**（門市主檔）的店號比對，將電話號碼形式的監工欄位替換為**監工姓名**
3. 輸出套用 **監工APP.xlsx** 模板格式的最終檔案

---

## 輸入檔案規格

### 檔案 1：ExportDispatch CSV（監工APP匯出）
- 檔名格式：`ExportDispatch_YYYYMMDDHHMMSS_開店.csv`
- 編碼：UTF-8
- 這是**主體資料**，所有列都要保留
- 關鍵欄位：

| 欄位 | 說明 |
|------|------|
| 區域 | 北一、北二、北三、中一、中二、南一、南二、桃竹一、桃竹二 |
| 門市 | 門市名稱 |
| 店號 | 6位數字字串（比對用主鍵） |
| 開幕日 | 格式 YYYY/MM/DD |
| 監工 | ⚠️ 這裡是電話號碼，格式如 `= "0917570200"`，**不是姓名** |
| 實際 | 整數 |
| 目標 | 整數 |
| 完成率 | 如 `100%` 或 `80%` |
| 缺失說明 | 文字，可能為空 |
| 1.表單上傳 ~ 5.初驗單作業 | 各項缺失數，整數 |
| 缺失總數 | 整數 |
| Unnamed: 15 | 空欄，忽略不用 |

### 檔案 2：活頁簿2.xlsx（門市主檔）
- 這是**監工姓名的來源**
- 關鍵欄位：

| 欄位 | 說明 |
|------|------|
| 門市店號（C欄） | 6位數字字串（比對用主鍵） |
| 監工（J欄） | **監工姓名**（如 黃O昇、徐辜O綺） |

### 檔案 3：監工APP.xlsx（模板）
- 空白模板，只有表頭，用來定義輸出格式
- 16 個欄位：開幕月、區域、門市、店號、開幕日、監工、實際、目標、完成率、缺失說明、1、2、3、4、5、缺失總數
- 表頭樣式：橘色底 `#F37721`、白色 Aptos 18pt 字

---

## 處理邏輯（依序執行）

### Step 1：讀取資料
```
讀取 CSV 時用 dtype=str 避免店號被轉成數字
讀取活頁簿2 時同樣 dtype=str
兩邊的店號都要 .str.strip() 去除空白
```

### Step 2：建立監工姓名查找表
```
從活頁簿2建立 { 門市店號 → 監工 } 字典
排除監工欄為空的列
若同一店號有多筆，取第一筆
```

### Step 3：組裝資料
```
以 CSV 為主體，逐列處理：
- 開幕月：從開幕日解析月份（整數）
- 監工：用店號查找活頁簿2的監工姓名（不是用CSV裡的電話號碼）
- 完成率：從 "100%" 格式轉為 0~1 小數
- 依開幕日升冪排序
- 丟棄 CSV 的 Unnamed: 15 空欄
```

### Step 4：寫入 Excel
```
套用監工APP模板格式：
- 表頭：橘色底 #F37721、白色 Aptos 18pt
- 資料：Aptos 12pt、置中對齊（門市和缺失說明靠左）
- 日期格式：YYYY/MM/DD
- 完成率格式：0%
- 交替行淡灰底色 #F5F5F5
- 監工未對應的列 F 欄標淡紅底 #FFC7CE
- 凍結首列、啟用自動篩選
- 欄寬沿用模板設定
```

### Step 5：驗證與輸出統計
```
輸出前必須驗證：
1. 輸出列數 = CSV 原始列數（一筆不能多、一筆不能少）
2. 抽查 3~5 個有對應的店號，確認監工姓名與活頁簿2一致
3. 確認未對應的店號確實不存在於活頁簿2
```

---

## 輸出檔案

- 檔名：`監工APP_彙整.xlsx`
- 格式：完全符合監工APP模板的 16 欄結構

## 注意事項

1. **CSV 的監工欄是電話號碼不是姓名**，格式如 `= "0917570200"`，絕對不要直接搬過去
2. **同一電話可能對應不同監工**（因為是門市的聯絡電話非監工個人電話），所以不能用電話反查姓名，必須用**店號**直接比對活頁簿2
3. **店號是字串**，不要轉成 int（避免前導零遺失或型別不符）
4. **活頁簿2 不一定涵蓋所有 CSV 的店號**，較早期的門市可能不在裡面，這些列的監工欄留空並標記即可
5. 每月的 CSV 欄位名稱可能微調（如缺失項目名稱），比對前先確認實際欄位

## Python 完整參考

```python
import pandas as pd
from openpyxl import Workbook
from openpyxl.styles import Font, PatternFill, Alignment, Border, Side

# === 讀取 ===
df_book = pd.read_excel('活頁簿2.xlsx', dtype=str)
df_csv = pd.read_csv('ExportDispatch_XXXXXXXX_開店.csv', dtype=str)
df_book['門市店號'] = df_book['門市店號'].str.strip()
df_csv['店號'] = df_csv['店號'].str.strip()

# === 查找表 ===
name_lookup = (df_book.dropna(subset=['監工'])
               .drop_duplicates(subset='門市店號', keep='first')
               .set_index('門市店號')['監工'].to_dict())

# === 組裝 ===
df_csv['開幕日_dt'] = pd.to_datetime(df_csv['開幕日'], errors='coerce')
df_csv['開幕月_val'] = df_csv['開幕日_dt'].dt.month.astype('Int64')
df_csv['監工_name'] = df_csv['店號'].map(name_lookup)
df_csv = df_csv.sort_values('開幕日_dt').reset_index(drop=True)

# === 建立 Excel ===
wb = Workbook()
ws = wb.active

# 表頭
headers = ['開幕月','區域','門市','店號','開幕日','監工',
           '實際','目標','完成率','缺失說明','1','2','3','4','5','缺失總數']
hdr_fill = PatternFill('solid', fgColor='F37721')
hdr_font = Font(name='Aptos', size=18, color='FFFFFF')
hdr_align = Alignment(horizontal='center', vertical='center')

for ci, h in enumerate(headers, 1):
    c = ws.cell(row=1, column=ci, value=h)
    c.font, c.fill, c.alignment = hdr_font, hdr_fill, hdr_align

# 欄寬
for col, w in {'A':16.2,'B':13,'C':16.3,'D':13.5,'E':20,'F':17.8,
               'G':13.2,'H':13,'I':16.2,'J':41.7,'K':12.7,'L':13,
               'M':13,'N':13,'O':13,'P':23.2}.items():
    ws.column_dimensions[col].width = w

# 欄位映射：(CSV欄名, 對齊, 資料型別)
col_spec = [
    ('開幕月_val','c','int'), ('區域','c','str'), ('門市','l','str'),
    ('店號','c','str'), ('開幕日_dt','c','date'), ('監工_name','c','str'),
    ('實際','c','int'), ('目標','c','int'), ('完成率','c','pct'),
    ('缺失說明','l','str'),
    ('1.表單上傳','c','int'), ('2.門市施工照片','c','int'),
    ('3.隱蔽性工程','c','int'), ('4.勞安工程','c','int'),
    ('5.初驗單作業','c','int'), ('缺失總數','c','int'),
]

bfont = Font(name='Aptos', size=12)
c_align = Alignment(horizontal='center', vertical='center')
l_align = Alignment(horizontal='left', vertical='center')
border = Border(left=Side('thin',color='D9D9D9'), right=Side('thin',color='D9D9D9'),
                top=Side('thin',color='D9D9D9'), bottom=Side('thin',color='D9D9D9'))
even_fill = PatternFill('solid', fgColor='F5F5F5')
miss_fill = PatternFill('solid', fgColor='FFC7CE')

for i, (_, row) in enumerate(df_csv.iterrows()):
    r = i + 2
    for ci, (col, al, dt) in enumerate(col_spec, 1):
        cell = ws.cell(row=r, column=ci)
        raw = row.get(col)
        if dt == 'int':
            try: val = int(float(raw))
            except: val = None
        elif dt == 'pct':
            try: val = float(str(raw).replace('%','')) / 100
            except: val = None
        elif dt == 'date':
            val = row['開幕日_dt'].to_pydatetime() if pd.notna(row['開幕日_dt']) else None
        elif dt == 'str':
            s = str(raw).strip() if pd.notna(raw) else ''
            val = s if s and s != 'nan' else None
        else: val = raw
        cell.value = val
        cell.font, cell.border = bfont, border
        cell.alignment = l_align if al == 'l' else c_align
        if dt == 'date' and val: cell.number_format = 'YYYY/MM/DD'
        if dt == 'pct' and val is not None: cell.number_format = '0%'
        if i % 2 == 1: cell.fill = even_fill
    if pd.isna(row['監工_name']):
        ws.cell(row=r, column=6).fill = miss_fill

ws.freeze_panes = 'A2'
ws.auto_filter.ref = f'A1:P{len(df_csv)+1}'
wb.save('監工APP_彙整.xlsx')

# === 驗證 ===
filled = df_csv['監工_name'].notna().sum()
missing = df_csv['監工_name'].isna().sum()
print(f"總筆數: {len(df_csv)}, 已填入: {filled}, 未對應: {missing}")
```
