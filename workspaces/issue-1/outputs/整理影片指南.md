# 整理 Facebook 影片（操作指南）

目的：用瀏覽器取得 Facebook 影片、下載、轉錄（語音轉文字）、並產出重點整理與摘要。此文件教你逐步操作，並提供可替代的線上/離線工具與範例指令。

重要提醒
- 若影片為私人或需登入才能觀看，必須使用有權限的 Facebook 帳號登入瀏覽器。下載/轉錄前請確認有權限與著作權授權。

步驟總覽
1. 在瀏覽器開啟影片頁面（提供的連結）。
2. 嘗試直接右鍵：若能看到「另存影片為...」，可直接下載。
3. 若無直接下載選項，使用開發者工具（DevTools）抓取影片來源。

使用開發者工具抓取影片來源（適用 Chrome/Edge/Firefox）
1. 在影片頁面按 F12 開啟 DevTools；選到 Network 分頁。
2. 勾選 Preserve log 並在 Filter 輸入 “media” 或 “mp4”。
3. 重新載入頁面或重新播放影片，觀察出現的 media 請求。
4. 右鍵該請求 → Open in new tab，或 Copy → Copy link address。
5. 在新分頁播放確認為影片檔；可右鍵另存或使用 curl 下載：

示例：
curl -L "<影片直連URL>" -o video.mp4

若無法取得直連（Facebook 會用分段/快取），可考慮：
- 在 Network → XHR/Fetch 或 Media 中找 m3u8，抓到 m3u8 後使用 ffmpeg：

ffmpeg -i "<playlist.m3u8>" -c copy video.mp4

線上下載器（風險與可用性）：fbdown.net、getfvid.com 等，有時失效或有廣告與隱私風險，請小心使用。

轉錄（Speech-to-Text）方法
A. YouTube 自動字幕（簡單、免費）
- 將影片上傳為 Unlisted（若可接受），對 YouTube 開啟自動字幕，生成後下載字幕檔（.srt）。

B. OpenAI Whisper（本地或雲端）
- 需安裝 ffmpeg 與 whisper，範例（Python / pip）:

pip install -U openai-whisper
whisper video.mp4 --model small --output_format txt

或使用 whisperx、whisper.cpp 取更好速度/精準度。

C. 線上服務（Otter.ai、Descript、Happy Scribe 等）
- 上傳影片即可獲得逐句稿與標點、分段，通常付費但介面友善。

整理與摘要（以稿本或字幕為基礎）
1. 取得純文字稿（.txt 或 .srt → 轉成純文字）。
2. 在本地用文本編輯器或 Google Docs 先做一次快速清理（移除時間碼、重複詞）。
3. 使用 ChatGPT 或類似工具要求生成：時間軸重點、5 行摘要、逐段要點、行動項目範例。

建議的 ChatGPT prompt 範例：
"請根據下列口語稿，產生：1) 5 行摘要；2) 每分鐘重點標註；3) 3 個可執行的建議。口語稿：<在此貼上或附檔>"

範例輸出格式（模板）
- 標題：
- 時間軸重點：
  - 00:00–00:30：XXX
  - 00:30–01:00：YYY
- 五行摘要：
- 建議/行動項目：

額外提示
- 若影片很長，可先用自動化工具分段轉錄（例如按每 10 分鐘切片），再分批送入摘要工具。
- 若不想公開影片，使用本地 Whisper + ChatGPT API（或本地 LLM）可避免上傳。

此檔不包含影片本體或轉錄結果。如需代為下載並整理影片，可回覆授權（或提供可公開存取之影片網址）。
