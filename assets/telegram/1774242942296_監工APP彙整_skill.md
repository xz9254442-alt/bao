# 監工APP 彙整技能

## 任務概述

以 **活頁簿2.xlsx（門市主檔）** 為主體，補入 **監工APP匯出資料** 的查檢完成狀況，輸出符合 **監工APP模板格式** 的 Excel 報表。

核心邏輯：活頁簿2 **每一筆都要保留**，它是主體。APP匯出只是補充查檢資料。

---

## 輸入檔案（3 個）

### 1. 活頁簿2.xlsx — 主檔（所有列都要出現在輸出中）

| 欄位 | 用途 |
|------|------|
| 區（A欄） | 輸出為「區域」 |
| 門市店號（C欄） | 比對主鍵（6位數字字串） |
| 門市（D欄） | 門市名稱 |
| 開幕日（I欄） | 日期，用來產生「開幕月」 |
| 監工（J欄） | ✅ **已經是監工姓名**，直接用 |

其餘欄位（店性、P-S、開店性質、工期起、工期迄）不帶入輸出。

### 2. 監工APP匯出 — 補充查檢資料

- 可能是 `.txt`（UTF-16 tab分隔）或 `.csv`（UTF-8 逗號分隔）
- 檔名格式可能為 `ExportDispatch_YYYYMMDDHHMMSS_開店.csv` 或 `監工APP.txt`

| 欄位 | 用途 |
|------|------|
| 店號 | 比對主鍵 |
| 實際 | 查檢完成數 |
| 目標 | 查檢目標數 |
| 完成率 | 如 100%、80% |
| 缺失說明 | 文字 |
| 1.表單上傳 ~ 5.初驗單作業 | 各項缺失數 |
| 缺失總數 | 缺失加總 |
| 監工 | ⚠️ 這裡是**電話號碼**，不要用！監工姓名從活頁簿2取 |

### 3. 監工APP彙整.xlsx — 空白模板

定義輸出的 16 欄結構與表頭格式（橘底白字 Aptos 18pt）。

---

## 處理邏輯

### Step 1：讀取檔案
```
活頁簿2：pd.read_excel(dtype=str)
APP匯出：
  - .txt → pd.read_csv(sep='\t', encoding='utf-16', dtype=str)
  - .csv → pd.read_csv(dtype=str)
兩邊店號都要 .str.strip()
```

### Step 2：從 APP匯出建立查找表
```
以店號為 key，取以下欄位：
  實際、目標、完成率、缺失說明、
  1.表單上傳、2.門市施工照片、3.隱蔽性工程、4.勞安工程、5.初驗單作業、缺失總數
若同一店號多筆取第一筆
```

### Step 3：組裝（活頁簿2 每一列都保留）
```
逐列處理活頁簿2的每筆資料：

  開幕月 ← 從活頁簿2的開幕日解析月份
  區域   ← 活頁簿2的「區」欄
  門市   ← 活頁簿2
  店號   ← 活頁簿2的「門市店號」
  開幕日 ← 活頁簿2
  監工   ← 活頁簿2（已是姓名，直接用）
  實際～缺失總數 ← 用店號查 APP匯出查找表，查不到就留空

依開幕日升冪排序
```

### Step 4：寫入 Excel（套模板格式）
```
表頭：橘色底 #F37721、白色 Aptos 18pt
資料：Aptos 12pt
對齊：置中（門市和缺失說明靠左）
日期格式：YYYY/MM/DD
完成率格式：0%
交替行底色：#F5F5F5
無APP資料的列 G~P 欄標淡黃底 #FFF2CC
凍結首列、啟用自動篩選
```

### Step 5：驗證
```
必須確認：
1. 輸出列數 = 活頁簿2 列數（一筆不多一筆不少）
2. 監工欄全部有姓名（因為來自活頁簿2，不應有空值）
3. 抽查 3~5 筆有APP資料的店號，確認實際/目標數值正確
```

## 輸出格式

| 欄 | 欄位名稱 | 資料來源 | 型別 |
|----|---------|---------|------|
| A | 開幕月 | 活頁簿2 開幕日→月份 | 整數 |
| B | 區域 | 活頁簿2「區」 | 文字 |
| C | 門市 | 活頁簿2 | 文字 |
| D | 店號 | 活頁簿2「門市店號」 | 文字 |
| E | 開幕日 | 活頁簿2 | 日期 YYYY/MM/DD |
| F | 監工 | 活頁簿2 | 文字（姓名） |

| H | 目標 | APP匯出 | 整數 |
| I | 完成率 | APP匯出 | 百分比 |

## 注意事項

1. **活頁簿2 是主檔**，全部列都要輸出，不能只輸出有APP資料的
2. **監工姓名從活頁簿2直接取**，APP匯出的監工欄是電話號碼，絕對不要用
3. **活頁簿2的欄位名是「區」不是「區域」**，輸出時轉為「區域」
4. **活頁簿2的欄位名是「門市店號」不是「店號」**，注意比對時的欄位名稱差異
5. **APP匯出格式不固定**：可能是 .txt（UTF-16 tab分隔）或 .csv（UTF-8），讀取前要判斷
6. **CSV 的監工欄可能有 `= "0917..."` 格式**（Excel公式跳脫），TXT則是純數字，但都不要用
7. **店號是字串**，不要轉 int
8. 尚未開幕的門市不會有APP資料，G~P留空是正常的

## Python 完整參考

```python
import pandas as pd
from openpyxl import Workbook
from openpyxl.styles import Font, PatternFill, Alignment, Border, Side
import os

# === 讀取主檔 ===
df_book = pd.read_excel('活頁簿2.xlsx', dtype=str)
df_book['門市店號'] = df_book['門市店號'].str.strip()

# === 讀取APP匯出（自動判斷格式）===
app_lookup = {}
for f in os.listdir('.'):
    if f.endswith('.txt') and 'APP' in f:
        df_app = pd.read_csv(f, sep='\t', dtype=str, encoding='utf-16')
        break
    elif f.endswith('.csv') and ('ExportDispatch' in f or 'APP' in f):
        df_app = pd.read_csv(f, dtype=str)
        break
else:
    df_app = None

if df_app is not None:
    df_app['店號'] = df_app['店號'].str.strip()
    app_cols = ['實際','目標','完成率','缺失說明',
                '1.表單上傳','2.門市施工照片','3.隱蔽性工程',
                '4.勞安工程','5.初驗單作業','缺失總數']
    app_lookup = df_app.drop_duplicates(subset='店號', keep='first') \
                       .set_index('店號')[app_cols].to_dict('index')

# === 組裝 ===
df_book['開幕日_dt'] = pd.to_datetime(df_book['開幕日'], errors='coerce')
df_book['開幕月'] = df_book['開幕日_dt'].dt.month.astype('Int64')
df_book = df_book.sort_values('開幕日_dt').reset_index(drop=True)

# === 建立 Excel ===
wb = Workbook()
ws = wb.active
headers = ['開幕月','區域','門市','店號','開幕日','監工',
           '實際','目標','完成率','缺失說明','1','2','3','4','5','缺失總數']

hdr_fill = PatternFill('solid', fgColor='F37721')
hdr_font = Font(name='Aptos', size=18, color='FFFFFF')
hdr_align = Alignment(horizontal='center', vertical='center')
for ci, h in enumerate(headers, 1):
    c = ws.cell(row=1, column=ci, value=h)
    c.font, c.fill, c.alignment = hdr_font, hdr_fill, hdr_align

for col, w in {'A':16.2,'B':13,'C':16.3,'D':13.5,'E':20,'F':17.8,
               'G':13.2,'H':13,'I':16.2,'J':41.7,'K':12.7,'L':13,
               'M':13,'N':13,'O':13,'P':23.2}.items():
    ws.column_dimensions[col].width = w

bfont = Font(name='Aptos', size=12)
c_al = Alignment(horizontal='center', vertical='center')
l_al = Alignment(horizontal='left', vertical='center')
bdr = Border(left=Side('thin',color='D9D9D9'), right=Side('thin',color='D9D9D9'),
             top=Side('thin',color='D9D9D9'), bottom=Side('thin',color='D9D9D9'))
even_fill = PatternFill('solid', fgColor='F5F5F5')
no_app = PatternFill('solid', fgColor='FFF2CC')

def si(v):
    try: return int(float(v)) if pd.notna(v) and str(v).strip() not in ('','nan') else None
    except: return None
def sp(v):
    try: return float(str(v).replace('%','').strip())/100 if pd.notna(v) and str(v).strip() not in ('','nan') else None
    except: return None
def ss(v):
    s = str(v).strip() if pd.notna(v) else ''
    return s if s and s != 'nan' else None

for i, (_, row) in enumerate(df_book.iterrows()):
    r = i + 2
    sid = row['門市店號']
    app = app_lookup.get(sid, {})
    dt = row['開幕日_dt'].to_pydatetime() if pd.notna(row['開幕日_dt']) else None

    vals = [
        (si(row['開幕月']), 'c'),
        (ss(row['區']), 'c'),
        (ss(row['門市']), 'l'),
        (ss(sid), 'c'),
        (dt, 'c'),
        (ss(row['監工']), 'c'),
        (si(app.get('實際')), 'c'),
        (si(app.get('目標')), 'c'),
        (sp(app.get('完成率')), 'c'),
        (ss(app.get('缺失說明')), 'l'),
        (si(app.get('1.表單上傳')), 'c'),
        (si(app.get('2.門市施工照片')), 'c'),
        (si(app.get('3.隱蔽性工程')), 'c'),
        (si(app.get('4.勞安工程')), 'c'),
        (si(app.get('5.初驗單作業')), 'c'),
        (si(app.get('缺失總數')), 'c'),
    ]

    for ci, (v, al) in enumerate(vals, 1):
        cell = ws.cell(row=r, column=ci, value=v)
        cell.font, cell.border = bfont, bdr
        cell.alignment = l_al if al == 'l' else c_al
        if ci == 5 and v: cell.number_format = 'YYYY/MM/DD'
        if ci == 9 and v is not None: cell.number_format = '0%'
        if i % 2 == 1: cell.fill = even_fill
    if not app:
        for ci in range(7, 17):
            ws.cell(row=r, column=ci).fill = no_app

ws.freeze_panes = 'A2'
ws.auto_filter.ref = f'A1:P{len(df_book)+1}'
wb.save('監工APP_彙整.xlsx')

matched = sum(1 for _, r in df_book.iterrows() if r['門市店號'] in app_lookup)
print(f"總筆數: {len(df_book)}, 有APP資料: {matched}, 無APP資料: {len(df_book)-matched}")
```
